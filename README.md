# Monster Mayhem - Heart Maze

## About the Project

Monster Mayhem - Heart Maze is a small browser game created using HTML, CSS and JavaScript for the Client Side Web Development assignment.

The player controls a monster that must move through a maze made of connected hexagons. The goal is to collect all the hearts and then reach the exit before running out of moves.

---

# How the Game Works

- The game board is made from connected hexagons.
- The monster starts at the entrance tile marked with **IN**.
- The player moves by clicking a neighbouring hexagon.
- Some hexagons contain rock walls that block movement.
- Hearts must be collected before the player can leave the maze.
- The exit tile is marked with **OUT**.
- The player has a limited number of moves to finish the game.

If the player collects all hearts and reaches the exit, they win the game.

If the moves reach zero before escaping, the game is over.

# AI Usage

AI tools were used only as support during the development process.

The AI was mainly used for:
- helping with ideas for the game mechanics
- troubleshooting JavaScript and CSS issues
- improving some parts of the code
- understanding how the hexagon movement system works

The final project was manually edited, tested and modified after using AI suggestions.

Some parts of the generated code were simplified and changed to better fit a first year student project and to make the code easier to understand and explain.
